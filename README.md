# Hani Birthday Website 🎂💌

A static, GitHub Pages-ready birthday website for Hani.

## Publish with GitHub Pages

1. Create a new **public** GitHub repository, for example:
   `hani-birthday`
2. Upload **all files in this folder** to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Save.
6. GitHub will provide a URL similar to:
   `https://YOUR-USERNAME.github.io/hani-birthday/`

The site is self-contained: the photos and styles are embedded in `index.html`, so no external asset folder is required.

## Site features

- Animated envelope intro
- Hani birthday greeting
- Medical-themed decorations (stethoscope, pills, bandage, syringe, heart, clipboard)
- Message / Flower / Cake flow
- Hani's uploaded photos
- Birthday collage
- Personalized Persian birthday letter
- Mobile responsive layout
- Swipe and keyboard navigation
